# Catálogo de Produtos

Aplicativo de exemplo em React Native com Expo. A tela exibe uma lista de produtos e seus preços usando `FlatList`.

## Requisitos

- Node.js e npm

## Executar no navegador

```bash
npm install
npm run web
```

## Executar no celular ou emulador

```bash
npm install
npm start
```

Depois, escaneie o QR code com o Expo Go ou abra o projeto em um emulador Android. Para iniciar diretamente no emulador Android, use `npm run android`.

## Estrutura

- `App.js`: tela do catálogo
- `app.json`: configuração do Expo
- `assets/`: ícones e imagens
- `package.json` e `package-lock.json`: dependências e comandos do projeto
